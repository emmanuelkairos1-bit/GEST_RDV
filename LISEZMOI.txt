GEST_RDV (version Node.js + MySQL) - sécurisée
==============================================
INSTALLATION
1) Installer Node.js 18 ou plus (LTS) : https://nodejs.org
2) Démarrer MySQL (XAMPP : Start) puis, dans phpMyAdmin, importer database/base.sql
3) Si MySQL a un mot de passe, modifier config.js
4) Dans le dossier du projet (terminal / cmd) :
       npm install
       npm start
5) Ouvrir http://localhost:3000/install  -> créer la structure et le Super Admin.

SÉCURITÉ
- Mots de passe : hachés avec bcrypt (coût 12), jamais stockés en clair.
  Règles : 10 à 72 octets, minuscule + majuscule + chiffre + symbole (tous les
  symboles, espaces et accents sont autorisés). Refusés : mots courants (même
  avec P@ssw0rd), suites (abcd, 1234, azerty), répétitions, mot de passe contenant
  le nom, l'email ou le nom de la structure.
- Blocage : 3 échecs sur un compte => blocage 2 heures (même avec le bon mot de
  passe, même en changeant de navigateur). 10 échecs depuis une même adresse IP
  => blocage 2 heures. Les blocages sont stockés dans MySQL.
  Pour débloquer en urgence : node debloquer.js
- Chiffrement (AES-256-GCM) des données personnelles : nom et email des
  utilisateurs ; nom, prénom, téléphone, email, motif et motif de report/refus des
  rendez-vous. La clé est dans le fichier secret.key créé au 1er lancement.
  >>> SAUVEGARDEZ secret.key (ailleurs que sur le serveur) : sans lui, les
  données chiffrées sont définitivement illisibles. Ne le partagez jamais.
  (Vous pouvez aussi fournir la clé via la variable GEST_RDV_KEY ou config.js.)
- Non chiffrés volontairement : code de suivi, statut, date, services, infos
  publiques de la structure (nécessaires aux filtres, statistiques et au suivi).
- En production : servir le site en HTTPS (Nginx/Caddy), puis mettre
  https: true et trustProxy: true dans config.js.

Changer le nom de la structure : Tableau de bord > Paramètres > Enregistrer.
